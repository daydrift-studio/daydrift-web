《度日：Daydrift》内置了成熟安全的模组管理系统。玩家可以通过安装社区模组获得更多的起居剧情、街道景观、自定义音乐或独特玩法。

---

## 1. 模组分发形态

社区发布的模组基于标准确定性归档分发：

1. **确定性分发压缩包（`.zip` / `.ddmod`）**：由官方工具链打包，内含完整的 `manifest.json`、源码/资源及 `daydrift.sig.json` 官方 Ed25519 签名存证；
2. **解压文件夹目录**：本地开发测试或直接放置于 `mods/{mod_id}/`，游戏内核自动解析。

---

## 2. 浏览器一键唤醒安装（daydrift:// 协议，推荐）

为了给玩家提供最无缝的模组体验，《度日》支持自定义 URL 协议（`daydrift://`），实现从网页商店到游戏客户端的一键秒级唤醒与自动安装：

### 2.1 安装流程
1. 访问官方模组商店（[daydrift-mods.blym.top](https://daydrift-mods.blym.top)）；
2. 找到心仪的模组，点击卡片上的 **「⚡ 一键安装」**（或在详情页点击「⚡ 一键安装到游戏」）；
3. 浏览器会提示打开关联的应用，点击允许唤醒《度日：Daydrift》；
4. **单实例智能调度**：
   - **若游戏已在运行**：客户端会自动将游戏窗口平滑置顶于前台，并弹出点阵风格的「外部模组安装确认」面板；
   - **若游戏尚未运行**：系统自动启动游戏客户端，并在就绪后弹出安装面板；
5. 点击面板中的 **「立即下载并安装」**，游戏将自动完成：
   - 官方 CDN 分发包流式拉取；
   - 提取并校验 Ed25519 官方防篡改签名与哈希完整性；
   - 解压至安全沙盒路径并立即自动激活生效；
6. 整个过程无需手动寻找 `AppData` 或移动任何文件。

### 2.2 协议关联说明
- 游戏桌面端（Windows / Linux / macOS）在启动时会自动向操作系统用户级注册表建立 `daydrift://` 协议关联（免管理员权限）；
- 若浏览器提示“未检测到关联应用”，只需启动一次最新版《度日》游戏即可完成自动注册修复。

## 3. 手动离线安装步骤

在没有网络或离线游玩场景下，可通过手动方式安装模组：

### 3.1 模组安装目录
游戏启动时会自动扫描以下本地路径下的所有有效模组：

| 操作系统 | 模组主目录路径 |
| :--- | :--- |
| **Windows** | `%APPDATA%/Godot/app_userdata/Daydrift/mods/` |
| **Linux / SteamOS** | `~/.local/share/godot/app_userdata/Daydrift/mods/` |
| **Android** | `Android/data/org.daydrift.game/files/mods/` |

> **便携模式提示**：在游戏执行文件同级目录下创建 `Daydrift/mods/` 文件夹，游戏会优先将其作为免安装便携目录读取。

### 3.2 操作步骤
1. 在模组详情页点击 **「下载分发包 (ZIP)」** 保存至本地；
2. 启动游戏，在主菜单点击 **「模组管理」** → 点击底部 **「导入模组包」** 按钮，选中下载的 `.zip` 文件；
3. 亦可手动将压缩包解压至上述的 `mods/{mod_id}/` 目录；
4. 在模组管理列表中勾选启用，点击「热重载」即可。

---

## 4. 模组管理面板功能

在游戏内「模组管理」菜单中，你可以查看与操作：

- **模组状态与详情**：查看模组名称、作者、版本号、详细描述与体系分类（Tier 1 纯数据、Tier 2 脚本沙盒、Tier 3 原生 PCK）；
- **排序与优先级 (Priority)**：数字越大的模组在加载链中优先级越高，当多个模组修改同一资源时，高优先级模组将生效；
- **依赖关系检测**：若某个模组依赖其他前置模组，管理面板会自动高亮提示缺失的依赖项；
- **全量干净回滚 (Clean Rollback)**：停用模组时，游戏内核会即时从场景树、内存与事件总线中剥离该模组的所有注入节点与临时数据，无需重启游戏。

---

## 5. 启动崩溃自愈保护机制 (`booting.lock`)

如果某个第三方模组存在严重逻辑缺陷，导致游戏在启动阶段闪退，游戏内置的 **自愈保护锁（Booting Lock）** 会自动触发介入：

1. **触发机制**：游戏启动时会在数据目录创建 `booting.lock` 标志文件。当主场景完全加载成功并就绪后，该标志文件被清除；
2. **异常捕获**：若游戏在启动阶段异常崩溃，下次启动时检测到残留的 `booting.lock`，将立即进入 **「安全恢复模式」**；
3. **保护策略**：
   - 自动暂时禁用所有第三方模组；
   - 弹窗提示玩家上次启动发生异常，并列出最近变更的模组清单；
   - 保护玩家的原生核心存档数据不受任何污染；
4. **恢复正常**：玩家可在安全模式下勾选排除有问题的模组，确认后重新进入正常游戏流程。
