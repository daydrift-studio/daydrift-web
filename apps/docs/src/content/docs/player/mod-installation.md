《度日：Daydrift》内置了成熟安全的模组管理系统。玩家可以通过安装社区模组获得更多的起居剧情、街道景观、自定义音乐或独特玩法。

---

## 1. 模组文件格式说明

社区发布的模组通常有两种分发载体：

1. **标准 `.ddmod` 文件**：由官方工具链打包的标准归档包，双击或直接放入指定目录即可识别；
2. **解压文件夹（包含 `manifest.json`）**：开发测试或手动提取的模组目录，直接放入目录亦可识别。

---

## 2. 模组安装目录

游戏启动时会自动扫描以下本地路径下的所有有效模组：

| 操作系统 | 模组主目录路径 |
| :--- | :--- |
| **Windows** | `%APPDATA%/Godot/app_userdata/Daydrift/mods/` |
| **Linux / SteamOS** | `~/.local/share/godot/app_userdata/Daydrift/mods/` |
| **Android** | `Android/data/org.daydrift.game/files/mods/` |

> **提示**：如果在游戏根目录下建立了同级 `mods/` 文件夹（便携模式），游戏亦会优先读取便携目录。

---

## 3. 手动安装模组步骤

1. 从官方 Mod 商店（[daydrift-mods.blym.top](https://daydrift-mods.blym.top)）或受信任的创作者页面下载 `.ddmod` 包；
2. 将下载到的 `.ddmod` 文件（例如 `rainy_coffee_v1.0.0.ddmod`）移动至上述对应的 `mods/` 目录；
3. 启动游戏，在主菜单点击 **「模组管理 (Mod Manager)」**；
4. 在列表中找到新安装的模组，点击开关将其设为 **「已启用」**；
5. 根据提示返回主界面或载入存档即可体验全新内容。

---

## 4. 模组管理面板功能

在游戏内「模组管理」菜单中，你可以查看与操作：

- **模组状态与详情**：查看模组名称、作者、版本号、详细描述与体系分类（Tier 1 纯数据、Tier 2 脚本沙盒、Tier 3 原生 PCK）；
- **排序与优先级 (Priority)**：数字越大的模组在加载链中优先级越高，当多个模组修改同一资源时，高优先级模组将生效；
- **依赖关系检测**：若某个模组依赖其他前置模组，管理面板会自动高亮提示缺失的依赖项；
- **全量干净回滚 (Clean Rollback)**：停用模组时，游戏内核会即时从场景树、内存与事件总线中剥离该模组的所有注入节点与临时数据，无需重启游戏。

---

## 5. 启动崩溃自愈保护机制 (`booting.lock`)

如果某个第三方模组存在严重逻辑缺陷，导致游戏在启动阶段闪退，游戏内置的 **自愈保护锁（Booting Lock）** 会自动触发介入：

1. **触发机制**：游戏启动时会在数据目录创建 `booting.lock` 标志文件。当主场景完全加载成功并就绪后，该标志文件被清除；
2. **异常捕获**：若游戏在启动阶段异常崩溃，下次启动时检测到残留的 `booting.lock`，将立即进入 **「安全恢复模式」**；
3. **保护策略**：
   - 自动暂时禁用所有第三方模组；
   - 弹窗提示玩家上次启动发生异常，并列出最近变更的模组清单；
   - 保护玩家的原生核心存档数据不受任何污染；
4. **恢复正常**：玩家可在安全模式下勾选排除有问题的模组，确认后重新进入正常游戏流程。
