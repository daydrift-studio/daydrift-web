## 1. 存档管理与跨平台迁移

### Q1: 我的游戏存档保存在电脑的哪个位置？
各操作系统下的存档根路径如下：
- **Windows**: `%APPDATA%/Godot/app_userdata/Daydrift/saves/`
- **Linux / Steam Deck**: `~/.local/share/godot/app_userdata/Daydrift/saves/`
- **Android**: `Android/data/org.daydrift.game/files/saves/`

### Q2: 如何把 Windows 电脑上的存档复制到 Steam Deck 或手机上？
1. 找到上述目录下的 `save_slot_1.json`（或当前使用的存档槽位）；
2. 将文件通过微信、QQ、USB 数据线或局域网互传至目标设备的对应目录；
3. 覆盖前建议将目标设备的原文件重命名备份；
4. 启动目标设备上的游戏即可无缝延续起居日常。

## 2. 操作设备与手柄适配

### Q1: 游戏支持哪些手柄？插入手柄后没有反应怎么办？
- 游戏原生支持 **Xbox Series / One 手柄**、**PlayStation 4/5 DualShock/DualSense**、**Nintendo Switch Pro 手柄** 以及各类符合标准 XInput / DirectInput 规范的国产手柄；
- 若无响应，请先确认手柄在操作系统层已被识别；若在 Steam 上以非 Steam 游戏方式启动，建议在 Steam 设置中开启「通用手柄控制器配置支持」。

### Q2: 触屏移动端虚拟摇杆手感不习惯？
在「系统设置 -> 控制」中，可以自由调整虚拟摇杆的显示透明度、半径大小，或切换为「轻触屏幕直接走动 (Tap to Walk)」模式。

## 3. 画面表现与帧率调优

### Q1: 在老旧轻薄本或掌机上运行偶有微卡顿？
1. 按 `F3` 键呼出全域性能监控面板：
   - 观察右上角 `Mem: XX%`（内存占比）与 `FPS / Frame Time`；
   - 观察 `GPU Usage: X.X% (Game)` 与当前渲染驱动类型；
2. 在「设置 -> 视频」中调整：
   - 将渲染模式由 **Forward+** 切换为 **Mobile (移动轻量管线)** 或 **Compatibility (兼容管线)**；
   - 开启或关闭「V-Sync 垂直同步」以匹配显示器刷新率；
   - 关闭全屏动态柔光抗锯齿。

## 4. 局域网联机与同游诊断

### Q1: 为什么在同一个 Wi-Fi 下搜不到好友创建的局域网房间？
请按以下顺序逐项排查：
1. **Windows 防火墙拦截**：房主在首次开服时，Windows 会弹窗询问是否允许网络通信。若误点了「取消」，需前往「Windows 安全中心 -> 防火墙和网络保护 -> 允许应用通过防火墙」，勾选允许《度日：Daydrift》在「专用网络」下通信；
2. **路由器开启了 AP 隔离 (AP Isolation)**：部分公共 Wi-Fi（如学校、咖啡厅或酒店网络）开启了设备隔离，禁止局域网内无线设备互访。此情况建议使用电脑开启移动热点，让手机或好友连接热点即可；
3. **备用直连方案**：让房主查看本机内网 IP（如 `192.168.1.108`），客机在游戏中选择「远程 IP 直连」，直接输入 `192.168.1.108:7777` 即可直连进入。

## 5. 模组与系统自愈

### Q1: 安装社区模组后游戏无法启动，闪退怎么办？
不用担心！游戏内置了 **`booting.lock` 自愈保护机制**：
- 再次启动游戏，系统会自动拦截并进入「安全恢复模式」；
- 系统将展示最近加载的模组列表，并自动禁用有问题的模组；
- 此时点击「进入游戏」，游戏将在纯净状态下加载，原版存档 100% 完好无损。
