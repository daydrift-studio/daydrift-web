在《度日：Daydrift》中，联机同游是一场非对抗、去功利化的陪伴体验。你可以与朋友在同一个像素小镇中静默并肩散步，或是共享一段温暖的日常闲聊。

---

## 1. 联机机制核心特性

- **零配置局域网发现**：同一 Wi-Fi 或局域网下，房主一键开启，客机自动扫描并展示房间卡片，无需繁琐输入 IP；
- **全平台跨端互通**：Windows、Linux 与 Android 客户端均可自由跨平台加入同一房间；
- **极简状态流**：同步仅包含必要的世界时钟、角色坐标、朝向与聊天气泡，保障低延迟与低流量消耗；
- **绝对去中心化隐私**：局域网联机全链路在本地网络闭环，不向任何第三方云服务上传玩家网络数据。

## 2. 局域网同游快速操作

### 2.1 成为房主（创建房间）
1. 启动游戏并进入任意存档或新游戏；
2. 按 `Esc` 呼出系统菜单，点击 **「联机漫游」**；
3. 选择 **「创建局域网房间」**；
4. 设置房间对外显示的名称（例如 *「午后两点的小憩」*），可选择是否设置入房密码；
5. 点击 **「确认开服」**。此时游戏后台启动轻量局域网广播服务，并在顶栏显示联机状态灯。

### 2.2 成为访客（加入房间）
1. 确保你的设备与房主连接至同一个无线路由器（或局域网交换机）；
2. 在主菜单或暂停菜单中点击 **「联机漫游 -> 搜索附近房间」**；
3. 列表将动态刷新展示已发现的房间名称、房主昵称、当前人数与延迟毫秒数；
4. 选中目标房间，点击 **「加入同游」** 即可完成瞬时接入。

## 3. 独立服务端直连 (公网 / 云主机)

若需要 7x24 小时保持世界常开，或与身处异地的朋友同游：
1. 房主或服主使用官方无头服务端包（参考 [服务端部署指南](/server/deployment/)）在云主机启动服务，并开放 TCP 端口（默认 `7777`）；
2. 玩家在客户端选择 **「联机漫游 -> 远程 IP 直连」**；
3. 输入服务器公网 IP 或解析域名（如 `drift.example.com`）及端口；
4. 如有密码，输入房间访问凭据后点击 **「连接」**。

## 4. 同游交互与操作

- **头顶名牌与动作**：进入房间后，你将能在街道与起居室看到其他旅人的像素角色及头顶淡灰色昵称标签；
- **实时对话气泡**：按 `T` 或 `/` 键呼出聊天输入框，键入文本回车发送。文本将以像素气泡形式在角色头顶悬浮展示数秒，并在左下角聊天记录中留存；
- **四时推进共识**：在多人环境下，时间推进与睡眠结算遵循房主规则或全局投票共识，避免时间冲突。

## 5. 网络连接排查 (FAQ)

- **Q: 局域网内无法搜索到好友的房间？**
  - **排查 1**：检查操作系统防火墙设置。Windows 首次开服会弹出「Windows Defender 安全警报」，请勾选允许「专用网络」通信；
  - **排查 2**：确认路由器是否开启了「AP 隔离（Client Isolation）」功能。若开启，无线设备之间将无法相互广播，需在路由器后台关闭该选项；
  - **排查 3**：可改用「直接输入局域网内网 IP（如 `192.168.1.100:7777`）」手动连接。
- **Q: 角色位置有瞬移或漂移现象？**
  - 按 `Tab` 查看网络延迟。若 RTT 超过 200ms，请检查是否处于弱信号 Wi-Fi 环境，或尝试切换为有线以太网接入。
