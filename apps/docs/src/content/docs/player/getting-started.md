欢迎来到《度日：Daydrift》的世界，旅人。

《度日：Daydrift》是一款慢节奏的生活切片与像素漫游游戏。游戏内没有紧迫的倒计时或惩罚性任务，你可以按照自己的步调穿梭于起居室与小镇街道之间。

---

## 1. 基础操作与控制键位

游戏支持键盘/鼠标、主流手柄（Xbox / PlayStation）以及移动触屏操作：

| 操作功能 | 键盘 / 鼠标按键 | 手柄按键 | 移动触屏手势 |
| :--- | :--- | :--- | :--- |
| **角色横向移动** | `A` / `D` 或 `←` / `→` | 左摇杆 / 方向键左右 | 屏幕左侧虚拟摇杆左右拖拽 |
| **互动 / 调查物件** | `E` 或 `Space` 或 回车 | `A` (Xbox) / `✕` (PS) | 直接轻触目标物体上的交互提示气泡 |
| **快速对话推进** | `Space` / `E` / 鼠标左键 | `A` (Xbox) / `✕` (PS) | 轻触对话文本区域 |
| **分支选项选择** | 鼠标点击选项 / 数字键 `1`-`4` | 方向键上下切换 + `A` 确认 | 轻触目标分支选项按钮 |
| **呼出文字聊天框** | `T` 或 `/` | 选定聊天按钮后按 `A` | 点击屏幕左下方聊天图标 |
| **查看在线旅人标牌** | `Tab` | `Y` (Xbox) / `△` (PS) | 点击屏幕顶栏旅人信息图标 |
| **调试监控 (F3 面板)** | `F3` | 无默认映射（需在设置开启） | 设置中开启调试悬浮窗 |
| **系统菜单 / 暂停** | `Esc` | `Start` / `Options` | 点击屏幕右上角齿轮设置图标 |

## 2. 界面布局与视觉指引

进入游戏后，核心视觉元素包含：

1. **时段指示器（顶栏左侧）**：实时展示当前生存天数与四时阶段（清晨、正午、傍晚、深夜）；
2. **交互提示气泡（浮于物件上方）**：当角色接近可交互实体（如床榻、烧水壶、书桌、窗户、街灯、长椅）时自动浮现，提示可触发的动作；
3. **对话与独白面板（屏幕中下部）**：采用低对比度复古点阵风格展示主角内心独白、剧情切片与 NPC 对白；
4. **同游旅人标牌（浮于其他角色头顶）**：联机状态下展示同伴昵称、离散动作与延迟状态。

## 3. 四时世界时钟与起居互动

游戏的世界时钟被划分为四个离散的宁静时段：

### 清晨 (Dawn)
- **环境氛围**：柔和微蓝晨光，街区尚未苏醒；
- **起居互动**：从卧室床榻苏醒，走近烧水壶互动，可冲泡热挂耳咖啡，聆听蒸汽升腾的细微白噪音；
- **时段推进**：完成清晨日常起居或走出房门，时钟将自然流转至正午。

### 正午 (Noon)
- **环境氛围**：明澈阳光铺洒街道，街道长卷展现活跃景象；
- **户外漫游**：走过横向拓宽的连绵街道，观察店铺招牌、在复古街灯旁的长椅驻足小憩，享受片刻宁静。

### 傍晚 (Dusk)
- **环境氛围**：橙红余晖笼罩小镇，晚风拂动树影；
- **闲适交互**：街道行人渐稀，路灯渐次亮起，适合整理背包或翻阅白日拾得的旧书信。

### 深夜 (Midnight)
- **环境氛围**：深蓝夜幕与点滴暖色灯光；
- **入眠结算**：返回卧室与床榻交互，选择「熄灯就寝」，系统将自动完成当日数据结算，保存进度并跨入次日清晨。

## 4. 存档与数据安全性

- **自动存档**：在每次跨天结算、进出房间门或完成关键剧情交互时，系统自动在本地写入原生加密快照；
- **跨平台目录**：
  - Windows: `%APPDATA%/Godot/app_userdata/Daydrift/saves/`
  - Linux: `~/.local/share/godot/app_userdata/Daydrift/saves/`
  - Android: `Android/data/org.daydrift.game/files/saves/`
- **纯本地离线原则**：存档数据完全归玩家所有，绝不未经许可上传至任何云端服务器。

## 5. 常见问题排查

- **Q: 移动时画面偶发微卡顿？**
  - 按 `F3` 检查帧率与显存开销。可在「设置 -> 显示」中切换 V-Sync 垂直同步模式，或将渲染模式由 Forward+ 切换为 Mobile / Compatibility。
- **Q: 如何重置设置或清除本地测试数据？**
  - 在「系统设置 -> 存储管理」中提供「重置所有偏好设置」选项，不会误删主存档文件。
