欢迎来到小镇，旅人。

《度日：Daydrift》是一款慢节奏的生活切片与日常漫游游戏。在这里没有压迫性的时间限制，你可以按照自己的步调生活与停留。

## 基础操作键位

| 操作 | 键盘按键 | 移动触屏手势 |
| :--- | :--- | :--- |
| **角色移动** | `W` / `A` / `S` / `D` 或方向键 | 屏幕左侧虚拟摇杆 |
| **交互与调查** | `E` 或 `Space` | 点击目标交互物体 |
| **快捷聊天输入** | `T` 或 `/` | 点击左下方聊天气泡 |
| **在线同游旅人标牌** | `Tab` | 点击顶栏旅人按钮 |
| **性能监控 (F3 面板)** | `F3` | 设置中开启调试面板 |
| **暂停 / 系统设置** | `Esc` | 点击右上角齿轮图标 |

## 世界时钟与四时流转

世界的时间被划分为四个离散的生活时段：
1. **清晨 (Dawn)**：晨光初照，适宜在卧室内冲泡热咖啡、翻阅笔记；
2. **正午 (Noon)**：门外街道热闹舒展，可以在复古街灯长椅处小憩；
3. **傍晚 (Dusk)**：夕阳余晖，天色渐暖；
4. **深夜 (Midnight)**：灯火隐入静谧，返回居所休息将进入新的一天。

## 局域网同游

在暂停菜单的「联机漫游」中，你可以：
- **创建局域网房间**：一键将自己的世界向身处同一 Wi-Fi 或局域网的朋友开放；
- **自动发现房间**：自动扫描并列出同一网络下的同游房间，免去手动输入 IP 的麻烦。
