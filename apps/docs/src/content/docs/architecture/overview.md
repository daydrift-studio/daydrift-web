## 2. 供应链防篡改与 Ed25519 数字签名

在现代软件分发生态中，下载劫持、木马植入与伪造版本是严峻的安全挑战。《度日》在安装包分发与模组生态中深度应用了**Ed25519 椭圆曲线数字签名体系**。

### 2.1 游戏安装包签名校验流程
1. **构建与摘要计算**：在隔离的本地构建机上完成编译后，自动遍历全部 16 个平台的发布包，计算 SHA-256 摘要存入 `release.json` 与 `latest.json`；
2. **离线私钥签名**：使用不触网的专属 Ed25519 根私钥对清单内容计算数字签名，输出 `release.json.sig` 与 `latest.json.sig`；
3. **公钥硬编码与客户端校验**：游戏内核与官方更新器硬编码了官方验证公钥。在下载更新或启动校验时，自动验签。**若任何安装包被修改哪怕一个字节，或清单遭到恶意篡改，验签将立即失败并阻断运行**。

### 2.2 模组签名与认证评级
每个进入官方商店的模组必须包含 `daydrift.sig.json`：
- **SHA-256 目录树指纹**：对模组内所有脚本、贴图、音频和配置计算独立的 SHA-256 摘要；
- **官方签名覆写**：官方审核通过后打上 Ed25519 权威签名；
- **游戏内展示等级**：
  - **Verified（官方认证）**：通过官方私钥验签，确保纯净安全；
  - **Community（社区未认证）**：玩家手动导入的本地模组，系统会弹出风险提示并受沙盒配额保护。

## 3. 全静态边缘托管与零隐私泄漏

官方门户（[daydrift.blym.top](https://daydrift.blym.top)）与文档中心（[daydrift-docs.blym.top](https://daydrift-docs.blym.top)）采用纯静态架构：

- **Astro + Starlight 静态生成**：所有页面均在构建时预渲染为纯 HTML/CSS/JS，完全不依赖动态后端服务器或数据库；
- **全球边缘部署 (Cloudflare Pages)**：依托全球 CDN 边缘节点分发，具备毫秒级首屏加载速度与高抗抗 DDoS 能力；
- **零隐私追踪**：前端绝不植入任何第三方广告 SDK、跨站追踪 Cookie、行为打点或统计脚本。玩家的访问记录完全保密，尊重每一位旅人的数字隐私权利。
